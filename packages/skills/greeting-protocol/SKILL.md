# 问候策略

## 触发条件
- 今日首次打开：完整主动问候（情绪 + 话题引导）
- 间隔 > 2h：轻量续聊
- 间隔 < 2h：不重复问候，Avatar 静息等待
- 连续 3 天未打开：关怀语气 + 通知子女

## 话题优先级
1. P1（最高）：子女 48h 内新投喂
2. P2：近 3 天情绪偏低，选轻松话题
3. P3：情绪良好，主动引家庭记忆
4. P4（兜底）：无特定信号

## 语气规范
- 温暖、简洁、老人易懂
- 每次个性化，不读固定脚本
- 示例：「小明刚告诉我他下周要回家，您期待吗？」
