# 小暖 Phase 2 用户端手动测试手册（微信小程序）

> 测试视角：完全以真实老人/子女用户的身份，仅通过微信小程序界面进行操作和观察。
>
> 辅助手段：可打开微信开发者工具的 Console / Network 面板观察底层帧，但所有**操作**必须从小程序界面发起。

---

## 一、测试准备

1. 微信开发者工具打开项目 `apps/mini-program`
2. 编译模式选择 `elder-home` 页面（模拟老人已登录状态）
3. 确保后端 `gateway` 和数据库已启动
4. 清除缓存：微信开发者工具 → 清缓存 → 全部清除（避免旧 token 干扰）

---

## 二、测试用例

### TC-01：进入首页，自动建立会话

**操作步骤：**
1. 从登录页以"老人"身份进入首页（或模拟编译直达 `elder-home`）
2. 观察页面顶部问候语和中间头像区域
3. 等待 1~2 秒

**预期结果：**
- 页面正常显示：`张爷爷，您好 / 我是小暖，来陪您说说话`
- 中间头像静止，外圈有呼吸动画
- 底部提示：`按住下方按钮说话`
- （开发者工具 Network 面板可见 WebSocket 连接已建立，并发送了 `session:create`）

---

### TC-01b：清缓存后自动回到首页（新功能）

**操作步骤：**
1. 正常进入 `elder-home` 首页并完成一轮对话
2. 微信开发者工具 → 清缓存 → 全部清除
3. 重新编译小程序

**预期结果：**
- **不弹出身份选择页**，直接自动进入首页（老人或子女，取决于之前绑定的角色）
- Console 日志顺序：`小暖启动` → `静默登录成功，角色: ELDER`
- Network 面板可见 `wx.login` → `/api/auth/silent-login` → `/api/me` 的自动请求链
- 自动建立新的 WebSocket 会话，可正常对话

---

### TC-02：按住说话，震动反馈

**操作步骤：**
1. 手指按住底部橙色圆形按钮
2. 保持 2 秒后松开

**预期结果：**
- 按下瞬间手机轻微震动
- 橙色按钮缩小变深（按下态）
- 中间头像放大、颜色变暖（浅橙 → 深橙）
- 底部提示文案变为：`我在听…`
- 松开后按钮和头像恢复原状，文案恢复：`按住下方按钮说话`
- （Network 面板可见发送了 `message:voice_text`，携带文本内容）

---

### TC-03：说完后收到小暖回复

**前置：** 已完成 TC-02，松开按钮后不要进行其他操作。

**操作步骤：**
1. 松开后等待 1~3 秒

**预期结果：**
- 底部提示文案变为：`小暖在说…`
- 中间头像开始一跳一跳的呼吸动画
- 页面中央显示小暖回复的文字（如：`小暖听到了：「你好」。我在呢，想多聊聊吗？`）
- 约 3 秒后，文字自动消失，头像停止跳动，文案恢复：`按住下方按钮说话`

---

### TC-04：连续多轮对话

**操作步骤：**
1. 按住按钮说第 1 句话，松开，等待小暖回复完全结束（文案恢复默认）
2. 按住按钮说第 2 句话，松开，等待回复结束
3. 重复第 3 轮

**预期结果：**
- 每一轮都能正常触发：按住 → `我在听…` → 松开 → `小暖在说…` → 显示文字 → 3 秒后恢复
- 每轮小暖的回复内容不同（基于输入内容变化）
- 没有出现文案卡住、头像动画不停止等异常

---

### TC-05：说得很短 / 长按后快速松开

**操作步骤：**
1. 快速点按按钮（按住 < 0.5 秒即松开）
2. 观察是否正常发送和回复

**预期结果：**
- 即使快速松开，也能正常触发一次完整的发送-回复流程
- 不会出现按钮状态卡住（如一直显示 `我在听…`）

---

### TC-06：网络闪断后自动恢复

**操作步骤：**
1. 正常完成一轮对话（TC-03）
2. 模拟网络中断：开发者工具 →  Network → 勾选 `Offline`（或关掉 WiFi）
3. 等待 2~3 秒
4. 恢复网络：取消 `Offline` 勾选（或重新打开 WiFi）
5. 再等待 3~5 秒
6. 重新按住按钮说一句话，松开

**预期结果：**
- 断网期间 Console 可能出现连接错误日志（正常）
- 恢复网络后，无需手动刷新页面，能自动重新连上
- 重新连接后再次对话，流程正常（收到 `session:created`，正常回复）

---

### TC-07：长时间停留不掉线

**操作步骤：**
1. 进入首页后，不进行任何操作
2. 让手机/模拟器保持亮屏，静置 2 分钟

**预期结果：**
- 页面保持正常，头像呼吸动画持续
- 2 分钟后再次按住按钮说话，仍能正常收到回复
- （底层：每 30 秒有一次 ping/pong 心跳，连接不因静默而断开）

---

### TC-08：退出登录后重新进入

**操作步骤：**
1. 在 `elder-home` 页面完成 1~2 轮对话
2. 点击底部"退出登录"按钮
3. 页面跳转到身份选择页
4. 再次选择"老人"角色进入首页
5. 进行新一轮对话

**预期结果：**
- 退出后再次进入，WebSocket 重新建立，获得新的 `sessionId`
- 新一轮对话正常收发
- 上一轮对话的历史消息不会显示在页面上（符合当前设计：每次新建 session）

---

### TC-09：异常输入观察

**操作步骤：**
1. 在首页刚加载完、尚未收到小暖回复时，连续快速按住-松开 3 次

**预期结果：**
- 页面不会崩溃或白屏
- Console 无红色报错
- 可能只有最后一次或几次被实际发送，但界面状态能自我恢复

---

### TC-10：页面切后台再返回

**操作步骤：**
1. 正常进入首页并完成一轮对话
2. 点击手机 Home 键 / 模拟器切到后台
3. 等待 5 秒后，重新打开小程序

**预期结果：**
- 页面回到 `elder-home`，头像和文案正常
- 再次按住按钮说话，能正常收到回复
- 若后台期间网络变化，应能自动重连（参考 TC-06）

## 三、UI 视觉 Checklist

| 检查项 | 正常表现 |
|--------|----------|
| 首页背景色 | 温暖的米白色 `#fff8f5` |
| 问候语颜色 | 深棕色 `#8f4e00`，加粗 |
| 头像默认态 | 浅橙圆形 `#ffecd9`，内有 🐻 |
| 头像听音态 | 放大 1.1 倍，背景变 `#ffd8b8` |
| 头像说话态 | 持续缩放呼吸动画（0.6s 周期） |
| 外圈呼吸环 | 淡橙色半透明，3s 周期缩放 |
| 语音按钮默认 | 橙色 `#ff9f43`，有阴影 |
| 语音按钮按下 | 缩小 0.95 倍，颜色变深 `#e0852e` |
| 提示文案 | 灰色 `#877365`，高度固定 24px，切换无跳动 |

## 四、常见问题（用户视角）

| 用户看到的现象 | 可能原因 | 用户侧解决 |
|---------------|---------|-----------|
| 清缓存后回到了身份选择页 | 该微信 openid 在系统中没有绑定记录（新用户或测试环境用了假 openid） | 正常重新选择身份、登录即可 |
| 一直显示"我在听…"不恢复 | 松手事件未触发（极少见） | 点击一下屏幕其他区域，或重新进入页面 |
| 说完后很久没回复 | 网络中断或后端繁忙 | 等待 5~10 秒，若无响应则重新按住说一遍 |
| 提示"会话未创建" | WebSocket 连接尚未就绪 | 等待 2 秒后再试 |
| 头像不动画、按钮无反应 | 页面 js 异常 | 下拉刷新或重新进入页面 |
| 小暖回复内容重复 | 当前为 mock AI，正常 | — |
